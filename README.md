# Pranav V P – Phoenix FX Portfolio
```
npm install
npm run dev      # local preview
npm run build    # production build -> dist/
```
## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. vercel.com → Add New Project → import the repo (Vite is auto-detected).
3. Click Deploy. Or run `npx vercel --prod` from this folder.

Replace `public/images/profile.png` any time to change the photo. Social links are in `src/App.jsx` (`LINKS`).
